\section*{Streszczenie}

Defense in depth — finalnie \textbf{2 modele w produkcji} (L1 XGBoost na TEXBAT, L2 XGBoost na Aissou), \textbf{3 odrzucone}: L3v1 + L3v2 IsolationForest (OpenSky — different threat surface, niższe F1, brak ground truth) oraz L4 LSTM-AE (underperforms L3v2 na każdej intensywności ataku, Faza 10). Wszystkie odrzucone ścieżki zachowane w repo i widoczne na pipeline diagramie dla transparentności (sekcja \emph{Iteration log} w README).

Headline: \textbf{TEXBAT ds7 OOD F1=0.984, Precision=1.000, Stealth phase 100\% recall}. Aissou binary F1=0.976. \textbf{Learning curve}: TEXBAT XGBoost saturuje już przy $\sim$250 próbkach (F1 > 0.95) — pełny zbiór 912 próbek dodaje tylko marginalne gains.

\textit{Pokrywa kryteria: 4 (Method Selection), 5 (Implementation), 6 (Evaluation), 7 (Comparison).}

\section*{Pipeline — architektura end-to-end (z odrzuconymi ścieżkami)}
\imgpage{pipeline_diagram.png}{Production: L1 + L2 + Ensemble OR + SHAP TreeExplainer. OpenSky/L3 path zaszarzony — odrzucony, ale widoczny dla transparentności}{Wyszarzone L3v1/L3v2 + dotted arrows pokazują, że ścieżka OpenSky była wyeksplorowana (model bundles + EDA + ewaluacja), ale nie weszła do produkcyjnego ensemble. Powody: (1) different threat surface — TEXBAT/Aissou widzą spoofing na poziomie sygnału/kanału, OpenSky tylko już-zspoofowane pozycje ADS-B; (2) F1 0.74--0.79 vs 0.98+ w supervised; (3) brak czystych labels (synthetic injection). Single inference API \texttt{ml/inference.py}, FastAPI :8000 + Next.js 16 :3000, sub-millisecond inference per scoring call.}

\section*{Learning curve — saturacja XGBoost przy $\sim$250 próbkach}
\imgpage{learning_curve.png}{TEXBAT XGBoost re-trenowany na fragmentach 5\%--100\% zbioru (cleanStatic+ds3, 912 próbek), 3 seedy per fraction, ewaluacja na ds7}{F1 saturuje przy $\sim$250 próbkach (F1 > 0.95), AUC plateauuje przy $\sim$1.0, Recall stabilny. Wniosek: dataset rozmiarem nie był bottleneckiem — pełny zbiór 912 próbek dodaje tylko $\sim$0.03 F1 vs 250 próbek. Implikacja praktyczna: w real-world deployment 200--300 oznakowanych próbek per scenariusz spoofing wystarczy do paper-grade detekcji.}
